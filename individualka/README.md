# Индивидуалка — тумба 120 со столешницей и умывальником

Индивидуальный заказ, отдельно от серий TL / TG. Вид от клиента: [vid_klienta.png](vid_klienta.png).

## Исходные данные (ориентировочно, уточняются по чертежу столешницы)

| Параметр | Значение |
|---|---|
| Ширина стены | 2000 мм |
| Тумба со столешницей | 1200 мм |
| Стиральная машина справа | 600 мм |
| Зона коммуникаций у стены | 120 мм |
| Глубина столешницы | 530 мм |
| Толщина столешницы | 20 мм |
| Высота тумбы | 850 мм, на ножках 100 мм |
| Чаша умывальника | 500 × 330 мм, врезная/интегрированная в столешницу |

## Секции (вид спереди, слева направо)

1. **400 мм** — корзина для белья.
2. **800 мм** — два выдвижных ящика.

## Важно

- **Чаша умывальника центрируется по секции ящиков 800 мм**, а не по всей тумбе 1200 мм
  (на картинке клиента — по центру тумбы, это НЕ так). Центр чаши ≈ 800 мм от левого края тумбы
  (400 + 800/2), т.е. 400 мм от правого края. Уточнить по чертежу столешницы.
- Верхний ящик — с вырезом под сифон по центру секции 800.

## Столешница — исходный чертёж клиента ([stoleshnitsa_ishodnaya.png](stoleshnitsa_ishodnaya.png))

1200 × 530 × 20 мм, умывальник **Boat 500** (снаружи 520 × 365, чаша 500 × 345, глубина 125/120, слив Ø45/75).
Вырез 520 мм: 620 мм от левого края, 60 мм от правого. **Центр слива 880 мм от левого края.**
По глубине: сзади 125–135 мм, спереди 40–50 мм.

**Нужна правка:** центр секции ящиков 800 мм от левого края → вырез сдвинуть на 80 мм влево:
**540 мм слева, 520 вырез, 140 мм справа** (по чаше 500: 550 / 500 / 150).
