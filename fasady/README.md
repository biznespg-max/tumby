## Ручка модели 2 — «Ручка Фрезерована Прохідна New» (стр. 113, ruchka-prohidna-114.png)
Только 19 мм, фарбованые матовые — можно. Мин. деталь 100×260, мин. сторона под ручку 220, мин. длина ручки 100,
от угла до ручки ≥ 60 (для непрохідної). Варианты выхода на торец #1 (R30, 135°), #2 (R23), #3 (R8, 90°).
У нас: на всю ширину, в стыке фасадов — у верхнего F1 по нижнему торцу, у нижнего F2 по верхнему (сверху у F1 умывальник
выступает на 3–6 мм и мешал бы пальцам). Вариант #2.

## Ручки для модели 3 (Сансет 64, 22 мм) — проверка 24.11.2026
Полный каталог ViyarFronts v7.6.2 лежит в `fasady/katalog_frezerovok_mdf_fasadov_v7.6.2.pdf` (+ текст `katalog_frezerovok_v7.6.2.txt`).
- В ViyarPro для фасада Сансет 64: «Обробка → Фрезеровані ручки» — **«Фрезеровані ручки недоступні»**.
- В каталоге фрезерованные ручки толщиной 22 мм есть только как отдельные типы фасада (гладкий фасад с ручкой):
  «Ручка Фрезерована під 45°» (стр. 113 PDF, № 112; 16/19/22, мин. 100×260) и «Фігурна Тип-2» (стр. 116, № 115; 16/19/22,
  мин. сторона под ручку 140, отступ от угла ≥ 40) — `ruchka45-113.png`, `ruchka_fig2-116.png`. С волной Сансет не совмещаются.
- Профильные ручки (Cosma M 622, Ferro Fiori M 8030/8040/8050/8060, UKW 4/5/7) и «Прохідна New», «Фігурна Тип-1» — только 19 мм.
- Варианты: «Сансет 64 Індивідуальний» + чертёж ручки (через менеджера), накладные ручки, или без ручек (push-to-open).

**Решение 24.11.2026 — ручка модели 3: Bravo Sunrise FX-050-320** (bravo-tm.com.ua; ZAMAK, монтаж фронтальный, 2 винта M4).
Размеры по чертежу Bravo: межцентровое 320, длина 372, стойки Ø15, вылет ≈23 мм. Ряд: 0 (кнопка), 128 (длина 180), 160, 224, 320.
Расчёт по волне Сансет 64 на фасаде 586: в центре фасада гребень («CR»), дно волн на ±32, ±96, ±160, ±224, ±288 мм.
- 320 → отверстия ±160 = **точно по дну волны** (дуга R≈130 при глубине ≈4 мм; под стойкой Ø15 зазор ≈0,2 мм — стоит ровно). Поля по 107 мм.
- 128 → ±64 = на гребне (стойка «качается», зазоры ≈1,6 мм по бокам); 160 и 224 → ±80/±112 = на склоне — не подходят.
- Кнопка (размер 0) по центру — на гребне, не подходит.
Винт: в дне волны остаётся ≈18 мм МДФ — проверить длину винтов в комплекте (M4×22/25).
