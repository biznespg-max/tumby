# Тумбы под умывальник — файлы для ВіЯр (ViyarPro)

Генератор деталировки тумб под мебельные умывальники. По модели, умывальнику и размеру
он выдаёт файл для онлайн-конструктора **ViyarPro** со всеми деталями, кромкой и присадкой
под минификсы, а также спецификацию, таблицу деталей и чертёж.

## Как устроено

```
umyvalniki/          каталог умывальников (размеры, слив)
  adamant-quanto.yaml      Quanto 60 / 70 / 80 / 90 / 100
  adamant-cers.yaml        Cers 60 / 70 / 90 (встают на тумбы Quanto)
  adamant-flat.yaml        Flat 60 / 70 / 80 / 100 (встают на тумбы Quanto)
modeli/              модели (серии) тумб: конструкция, материалы, фасады
  line/model.yaml          серия TL «Line» (крашеный МДФ)
  gold/model.yaml          серия TG «Gold» (МДФ Acrylux «Античне золото»)
izdeliya/            готовые файлы для заказа (собираются автоматически)
  TL-Q60 … TL-Q100, TG-Q60 … TG-Q100
generator/           общий код: деталировка, минификсы (joints.py), файл ViyarPro, спецификация, чертёж
tests/               проверка сборки для каждого изделия
build.py             собрать все изделия
```

Умывальники Cers (60 / 70 / 90) и Flat (60 / 70 / 80 / 100) встают на тумбы TL-Q того же размера без изменений — см. [SOVMESTIMOST.md](SOVMESTIMOST.md).

**Артикул** = код серии + код умывальника + размер: **TL-Q80** — серия Line, Adamant Quanto 80.
Цвет — опция заказа, на файл для ViyarPro не влияет.

## Серия TL «Line»

Подвесная тумба с двумя ящиками под мебельный умывальник.

- Корпус: **влагостойкий МДФ 19 мм под покраску** (Коростень, код 55814), без кромки.
  Ширина = ширина умывальника − 10 мм, глубина 425 мм (+ фасад 19 = 444, умывальник 447).
  Высота 650 мм. Задняя стенка открыта под коммуникации.
- Ящики (все серии и ширины, с 20.11.2026): направляющие **Häfele Matrix Runner UM A30** — скрытый монтаж,
  полное выдвижение, доводчик, клипсы 3D, 30 кг, **NL=400** (арт. 433.03.284). Короба из ДСП 18 мм длиной 400 мм,
  внутренняя ширина короба = внутр. ширина корпуса − 49. Мин. глубина корпуса под NL=400 — 418 мм, поэтому
  **задняя нижняя царга K5 поднята на 50 мм над дном** (`rear_bottom_rail_lift`): под ней проходят задние концы направляющих.
  Верхний ящик с П-образным вырезом под сифон — без фрезеровки, только прямоугольные детали.
- Передняя верхняя царга K3 стоит на ребре (80 × 19 мм) заподлицо с передом корпуса, за верхним фасадом;
  умывальник спереди лежит на её торце, чаша в неё не упирается.
- Фасады: два фасада ящиков, крашеный МДФ ViyarFronts 19 мм, фрезеровка **«Рамка з лініями»**, мат,
  цвет **NCS S 3010-Y50R** (корпус и фасады одним цветом). Заказываются отдельно.
- Соединения (во всех сериях, в корпусе и в ящиках): **минификсы**, конфирматов нет. Шток Ø5 × 11 в пласти,
  отверстие Ø8 × 34 в торце, эксцентрик Ø15 на 24 мм от торца. Все отверстия глухие и только изнутри —
  снаружи изделия ничего не видно. Где левая и правая детали сверлятся по-разному, они идут зеркальной
  парой (K1Л / K1П, V1Л / V1П, V4Л / V4П). Отверстия с обратной стороны детали — отдельная операция в файле ViyarPro.

## Серия TG «Gold»

Подвесная, 2 ящика, царга K3 на ребре, те же умывальники и размеры, что у TL. Отличия — материал и **вкладные фасады**.

- Боковины, царги и фасады: **МДФ Niemann Acrylux-MAT (AFP) PREMIUM «Античне золото» 8859, 18 мм, односторонний**
  (изнанка белая), код ВіЯр 235316, лист 2800 × 1300. Кромка ABS «Античне золото» 23 × 1 мм (код 186180).
- **Дно** — белое влагостойкое ДСП Kronospan 8100 SM «Білий перламутровий» P3 18 мм (код 178719 — складская программа ВіЯр; прежний 8685, код 205550, только остатки), кромка белая 0,8 мм.

- **Фасады вкладные**: стоят между боковинами вровень с их передними торцами, по бокам видны торцы корпуса.
  Дно и передняя царга отступают за фасад на 18 мм. Фасады гладкие, без ручек и вырезов (ручки — позже).
- Боковины зеркальные (K1Л / K1П), декором наружу.

  2 мм (код 14448) и 0,8 мм (код 87208). TG-Q90 и TG-Q100 — на Hettich, короба 16 мм (код 31930, уточнить
  наличие; запасной вариант — белый Kronospan 0110 16 мм, код 23724).

## Как заказать в ViyarPro

1. ViyarPro → **Конвертація** → формат **GibLab** → загрузить `izdeliya/<артикул>/<артикул>.project`.
2. Заменить материалы на позиции каталога (импорт GibLab названия не сопоставляет):
   корпус (K1–K5) — МДФ 19 мм код 55814 без кромки; короба (N, V) — ДСП 5981 Кашемір код 178718,
   кромка 2 мм на верхние торцы, 0,8 мм на остальные.
3. Фасады — отдельно в разделе фарбованих фасадів, размеры в `spec.md`.

## Добавить размер, умывальник или модель

```bash
pip install -r requirements.txt
# новый размер:      строка в umyvalniki/<умывальник>.yaml и в izdeliya модели
# новый умывальник:  новый файл в umyvalniki/
# новая модель:      новая папка в modeli/
python build.py                  # пересобрать все изделия
python -m pytest tests           # проверка: минификсы сходятся, снаружи отверстий нет, всё помещается
```
