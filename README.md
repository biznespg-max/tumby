# Тумба под умывальник для заказа в ВіЯр (ViyarPro)

Генератор деталировки подвесной тумбы с двумя ящиками под мебельный умывальник.
Берёт размеры из `tumba/config.py` и выдаёт файл для онлайн-конструктора **ViyarPro**
со всеми деталями, кромкой и присадкой под конфирматы.

**Первая модель:** тумба 790 × 650 × 425 мм под **Adamant Quanto 80** (800 × 447 × 140).

## Готовые файлы (папка `out/`)

| Файл | Что это |
|---|---|
| `tumba.project` | Файл для ViyarPro: 16 позиций / 22 детали ДСП, кромка, 138 отверстий |
| `spec.md` | Спецификация: детали, фасады, фурнитура, сборка, что проверить |
| `cutlist.csv` | Таблица деталей (открывается в Excel) |
| `drawing.svg` | Чертёж: вид спереди, разрез, верхний ящик с вырезом под сифон |

## Как загрузить в ViyarPro

1. Войти на viyar.ua → конструктор **ViyarPro** → **Конвертація** → формат **GibLab**.
2. Загрузить `out/tumba.project`.
3. Заменить материал на *ДСП Kronospan 8685 BS Білий Сніг вологостійке Р3 18 мм (код 205550)*
   (или другой влагостойкий Р3 цвет), а кромку — на кромку из сопутствующих товаров к этому ДСП:
   2 мм для видимых торцов, 0,8 мм для остальных. Импорт GibLab названия материалов не сопоставляет.
4. Проверить детали и присадку на схемах ViyarPro, оформить заказ.

Фасады (МДФ влагостойкий, крашеный, с фрезеровкой) заказываются отдельно в разделе фасадов —
размеры в `spec.md`.

## Конструкция

- Корпус: 2 боковины, дно, передняя царга (лежит под умывальником), задняя верхняя царга
  (через неё тумба вешается на стену), задняя нижняя царга. Задняя стенка открыта под коммуникации.
- Ящики на скрытых направляющих **Muller Profi Line 18 мм, 3D, с доводчиком, L=400** (код ВіЯр 42135):
  короба из того же влагостойкого ДСП 18 мм.
- Верхний ящик с **П-образным вырезом под сифон**, собранным только из прямоугольных деталей —
  без фрезеровки.
- Все соединения — конфирматы 7×50 (в пласти Ø7 насквозь, в торце Ø5 × 35).

## Изменить размеры

```bash
# правим tumba/config.py, затем:
python generate.py               # пересобрать файлы в out/
python tests/test_assembly.py    # проверка: все отверстия сходятся
```

Проверка виртуально собирает корпус и ящики в 3D и убеждается, что каждое отверстие
в пласти попадает в ответное отверстие в торце, что тумба не шире и не глубже умывальника,
что направляющие помещаются, а короб верхнего ящика проходит под чашей.

## ⚠️ Перед первым заказом

- Пробная загрузка: убедиться, что ViyarPro правильно показывает детали и отверстия.
- Измерить положение слива на реальном умывальнике (`drain_from_front`, сейчас 160 мм).
- Сверить вычет ширины короба (`drawer_inner_deduct = 49`) со схемой из упаковки Muller.

Формат GibLab для ViyarPro описан по открытому проекту
[agav/ocl-viyar](https://github.com/agav/ocl-viyar) (плагин SketchUp → ViyarPro).
